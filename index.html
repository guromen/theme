HTML-атрибуты

Когда браузер парсит HTML, чтобы создать DOM-объекты для тегов, он распознаёт стандартные атрибуты и создаёт DOM-свойства для них. Но, например, body.type // undefined: DOM-свойство не создалось, потому что оно нестандартное. Таким образом, для нестандартных атрибутов не будет соответствующих DOM-свойств. Есть ли способ получить такие атрибуты? Конечно. Все атрибуты доступны с помощью следующих методов, что написано в HTML: -elem.hasAttribute(name) – проверяет наличие атрибута. -elem.getAttribute(name) – получает значение атрибута. -elem.setAttribute(name, value) – устанавливает значение атрибута. -elem.removeAttribute(name) – удаляет атрибут. -elem.attributes: коллекция объектов name, value

Но как его прочитать? alert(document.body.style.color); // пусто alert(document.body.style.marginTop);// пусто Есть две концепции в [CSS]: 1. _Вычисленное_ (computed) значение – это то, которое получено после применения всех CSS-правил и CSS-наследования. Например, `height:1em` или `font-size:125%`. 2. _Окончательное_ ([resolved]) значение – непосредственно применяемое к элементу. Значения `1em` или `125%` являются относительными. Браузер берёт вычисленное значение и делает все единицы измерения фиксированными и абсолютными, например, `height:20px` или `font-size:16px`. Для геометрических свойств разрешённые значения могут иметь плавающую точку, например, `width:50.5px`. Давным-давно `getComputedStyle` был создан для получения вычисленных значений, но оказалось, что окончательные значения гораздо удобнее, и стандарт изменился. Так что, в настоящее время `getComputedStyle` фактически возвращает окончательное значение свойства, для геометрии оно обычно в пикселях. Отображение (display) display — это основа того, как элемент ведёт себя в потоке страницы**. Основные значения 1. block — блочный элемент (занимает всю ширину, переносит строки). Примеры:div, p, h1 div { display: block; } 2. inline — строчный элемент (идёт в строке, ширину задавать нельзя). Примеры: span, a span { display: inline; } 3. inline-block — как `inline`, но можно задавать ширину и высоту. Удобно для кнопок. 4. flex — гибкий контейнер для расположения элементов. .box { display: flex; gap: 10px; } ➝ Позволяет легко выравнивать по центру: .center { display: flex; justify-content: center; /* по горизонтали */ align-items: center; /* по вертикали */ } 5. grid - современная сетка (для сложных макетов). 6. none — скрывает элемент (он исчезает из потока). Позиционирование (position) `position` определяет, как именно элемент располагается на странице Основные типы 1. static (по умолчанию) Элемент стоит на своём месте. Смещать нельзя. 2. relative Элемент остаётся в потоке, но можно сдвинуть `top / left / right / bottom`. .box { position: relative; top: 10px; /* сдвинется вниз */ left: 20px; /* и вправо */ } 3. absolute Элемент выпадает из потока и позиционируется относительно ближайшего предка с position: relative. .parent { position: relative; width: 200px; height: 200px; } .child { position: absolute; top: 0; right: 0; /* прижмётся к углу */ } 4. fixed Прилипает к экрану и остаётся при скролле. Часто используют для шапок или кнопки "наверх". .menu { position: fixed; top: 0; left: 0; width: 100%; } 5. sticky Гибрид relative и fixed: элемент движется со страницей, пока не "прилипнет" к указанной границе. h2 { position: sticky; top: 0; /* прилипает к верхней границе */ } z-index (порядок наложения) Когда элементы перекрываются — `z-index` решает, кто сверху. .box1 { z-index: 1; } .box2 { z-index: 10; } /* будет выше */ Совместное использование 👉 Часто используют комбинации: - `display: flex` + `position: relative` для контейнера - `position: absolute` для вложенных элементов (например, всплывающих окон, подсказок) - `position: fixed` для меню, футеров, кнопок
