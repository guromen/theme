Отображение (display) display — это основа того, как элемент ведёт себя в потоке страницы**. Основные значения 1. block — блочный элемент (занимает всю ширину, переносит строки). Позиционирование (position) `position` определяет, как именно элемент располагается на странице Основные типы 1. static (по умолчанию) Элемент стоит на своём месте. Смещать нельзя. 2. relative Элемент остаётся в потоке, но можно сдвинуть `top / left / right / bottom`. .box { position: relative; top: 10px; /* сдвинется вниз */ left: 20px; /* и вправо */ } 3. absolute Элемент выпадает из потока и позиционируется относительно ближайшего предка с position: relative. .parent { position: relative; width: 200px; height: 200px; } .child { position: absolute; top: 0; right: 0; /* прижмётся к углу */ } 4. fixed Прилипает к экрану и остаётся при скролле. Часто используют для шапок или кнопки "наверх". .menu { position: fixed; top: 0; left: 0; width: 100%; } 5. sticky Гибрид relative и fixed: элемент движется со страницей, пока не "прилипнет" к указанной границе. h2 { position: sticky; top: 0; /* прилипает к верхней границе */ } z-index (порядок наложения) Когда элементы перекрываются — `z-index` решает, кто сверху. .box1 { z-index: 1; } .box2 { z-index: 10; } /* будет выше */ Совместное использование 👉 Часто используют комбинации: - `display: flex` + `position: relative` для контейнера - `position: absolute` для вложенных элементов (например, всплывающих окон, подсказок) - `position: fixed` для меню, футеров, кнопок В HTML-разметке все элементы меню являются не кнопками, а ссылками, то есть тегами a. Всплытие и погружение Всплытие - ловит клики по своим дочерним элементам. При наступлении события – самый глубоко вложенный элемент, на котором оно произошло, помечается как «целевой» (`event.target`). - Затем событие сначала двигается вниз от корня документа к event.target, по пути вызывая обработчики, поставленные через `addEventListener(...., true)`, где `true` – это сокращение для `{capture: true}`. - Далее обработчики вызываются на целевом элементе. - Далее событие двигается от `event.target` вверх к корню документа, по пути вызывая обработчики, поставленные через `on'event'` и `addEventListener` без третьего аргумента или с третьим аргументом равным `false`. Каждый обработчик имеет доступ к свойствам события `event`: - `event.target` – самый глубокий элемент, на котором произошло событие. - `event.currentTarget` (=`this`) – элемент, на котором в данный момент сработал обработчик (тот, на котором «висит» конкретный обработчик) - `event.eventPhase`– на какой фазе он сработал (погружение=1, фаза цели=2, всплытие=3). Любой обработчик может остановить событие вызовом `event.stopPropagation()`, но делать это не рекомендуется, так как в дальнейшем это событие может понадобиться, иногда для самых неожиданных вещей. В современной разработке стадия погружения используется очень редко Обработчики, добавленные через on'event'-свойство или через HTML-атрибуты, или через addEventListener(event, handler) с двумя аргументами, ничего не знают о фазе погружения, а работают только на 2-ой и 3-ей фазах.
